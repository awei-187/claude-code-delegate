# Changelog

## 1.0.0 - 2026-09-10

- Added durable visible/detached jobs with required `status` and `result` retrieval.
- Added file-only Claude permissions and strict MCP isolation.
- Added shell-free structured verification with up to two same-session repair rounds.
- Added per-Claude, verification, and whole-job timeouts with process-tree termination.
- Added canonical path containment for delegated roots, prompt files, and verification directories.
- Added versioned result JSON, stable error codes, effective-model reporting, bounded logs, and validated cleanup.
- Added cross-platform fake-CLI regression tests, release synchronization, CI, privacy, and security documentation.
